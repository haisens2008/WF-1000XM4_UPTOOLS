SONY WF-1000XM4 耳机刷机工具

索尼 WF-1000XM4 耳机的 USB 的固件刷机工具
本软件通过充电盒可以单只刷写处于不同版本固件的耳机。
本软件为 audiospare.exe 的图形界面封装，仅供个人学习、研究与设备维护使用。
本项目基于公众使用的audiospare.exe, hidapi.dll, config.ini — HID更新工具来自 audiospare.com
随附固件来自https://github.com/lzghzr/MDR_Proxy/firmware/2948
本界面程序仅做命令调用与结果展示，不修改、不破解任何固件内容。
请勿将本软件及随附固件用于任何商业用途或非法分发。
本软件仅测试过SONY WF-1000XM4 耳机，其他型号未作测试。

这个软件有什么用？
当一个耳机丢失或损坏后配对了另一个不同的版本耳机。
左右耳机运行在不同的固件版本上（例如Ver 0126 vs Ver 0231）。
耳机无法配对 Sound Connect 应用拒绝更新它们。

你想强制使用特定的固件版本，比如0126版本是公认静噪效果最好的版本。

官方索尼软件包，可以从https://github.com/lzghzr/MDR_Proxy/firmware/2948 获得

要求
Windows（该工具是一个32位Windows可执行文件）
一根 USB-C 数据线（非仅充电线）
电脑上的一个USB接口（台式机背面的接口更稳定）

步骤 1 — 连接耳机
💡 重要提示：

将两个耳机放入充电盒中。

使用 USB-C 数据线将充电盒连接到电脑。
如果听不到USB插入的提示音请：
打开并关闭耳机盒盖15-20次，直到电脑发出提示音（此时耳机已激活且连接稳定）。

步骤 3 — 刷写固件
如果耳机运行的是不同版本，请逐一刷机，使它们最终运行在同一版本上：

发送完成固件后，保持USB连接至少10分钟，耳机才能自己完成升级。

如果两个耳机已经是同一版本，你可以同时刷写它们。
